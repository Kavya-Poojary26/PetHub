# PetHub 🐾

PetHub is a pet management web application developed using Java Full Stack technologies. The project helps users manage pet-related information such as pet details, adoption, services, and user management through an easy-to-use web interface.

---

## 🚀 Features

* User Registration and Login
* Add and Manage Pet Details
* Pet Adoption Information
* Responsive User Interface
* Database Integration
* CRUD Operations

---

## 🛠 Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Java
* JSP
* Servlets

### Database

* MySQL

### Tools

* VS Code / Eclipse
* Apache Tomcat
* Git & GitHub
